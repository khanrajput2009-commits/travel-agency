# Travel Agency Website 🌍✈️

Welcome to the **Travel Agency Website** repository! This is a frontend web project designed to showcase travel destinations, packages, and a smooth booking experience for users.

## 🚀 Live Demo
You can check out the live website here: 
👉 [https://khanrajput2009-commits.github.io/travel-agency/]

## ✨ Features
- **Stunning Homepage:** Attractive hero section with popular travel destinations and highlights.
- **Fully Responsive:** Optimized smoothly for desktops, tablets, and mobile devices.
- **Interactive Navigation:** Clean layout and easy-to-use menu options.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript**

## 💻 How to Run Locally
1. Clone this repository or download the ZIP.
2. Open `index.html` in your web browser.
